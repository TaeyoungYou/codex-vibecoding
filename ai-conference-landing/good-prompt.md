목표:
@index.html의 UI를 깔끔하고 정돈된 형태로 개선해줘.
기존 페이지의 목적과 콘텐츠는 유지하면서,
레이아웃, 간격, 정렬, 타이포그래피, 시각적 계층 구조를 개선해줘.

컨텍스트:
별도 없음.
필요한 경우 현재 프로젝트 구조와 관련 스타일 파일을 직접 확인해.

범위:

- @index.html 외의 다른 HTML 파일은 수정하지마.
- 기존 색상 테마와 전반적인 디자인 방향은 유지해줘.
- 필요하면 @styles.css나 assets폴더안에 파일을 확인해도 됨.
- 기존 기능이나 콘텐츠는 임의로 삭제하지마.
- 새로운 라이브러리나 프레임워크는 가능한 추가하지 마. 해야한다면, 나에게 권한을 물어봐.

작업 모드:

- 코드를 수정하기 전에 먼저 현재 @index.html 구조와 디자인을 분석해.
- 바로 수정하지 말고, 먼저 어떤 부분을 개선할지 간단한 작업 계획을 세워.
- 큰 구조 변경보다는 최소한의 수정으로 UI를 개선해.
- 불필요한 리펙토링이나 파일 분리는 하지마.
- 기존 기능이 깨지지 않도록 수정해.

검증:

- 수정 후, HTML/CSS 문법 오류가 없는지 확인해.
- 프로젝트에 빌드 명령이 존재하면 빌드를 실행해서 성공하는 지 확인해.
- 수정으로 인해 기존 레이아웃이나 기능이 깨지지 않았는지 확인해.
- 검증 중 문제가 발견되면 수정한 뒤 다시 확인해.

출력 형식:

- 수정한 파일, 구현한 기능 요약, 검증 결과를 간단히 알려줘
