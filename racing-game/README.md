# APEX RUSH

브라우저에서 플레이하는 3D 아케이드 레이싱 게임입니다. 5명의 AI 경쟁자를 추월하며 3랩을 완주합니다.

## 실행

Windows PowerShell에서는 다음 명령으로 실행합니다.

```powershell
cd C:\Study\Codex\codex-vibecoding\racing-game
npm.cmd install
npm.cmd run dev
```

표시된 로컬 주소를 브라우저에서 엽니다. 자세한 시작 방법과 문제 해결은 [게임 시작 가이드](PLAY_GUIDE.md)를 참조하세요.

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 가속 | W / ↑ | GO |
| 브레이크 / 후진 | S / ↓ | BRAKE |
| 조향 | A, D / ←, → | ←, → |
| 니트로 | Space | ⚡ |
| 일시정지 | P / Esc | 상단 Ⅱ 버튼 |
| 트랙으로 복귀 | R | 상단 ↺ 버튼 |

니트로는 주행 중 다시 충전됩니다. 화면 상단의 사운드 버튼으로 엔진 소리를 켤 수 있습니다.
