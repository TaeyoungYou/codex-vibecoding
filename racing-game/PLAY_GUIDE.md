# APEX RUSH 게임 가이드

## 게임 시작

1. **[게임 열기](https://taeyoungyou.github.io/codex-vibecoding/)** 링크를 엽니다. 설치나 npm 명령은 필요하지 않습니다.
2. **레이스 시작**을 누르고 3, 2, 1 카운트다운을 기다립니다.
3. 가속과 조향으로 AI 차량 5대를 추월하며 3랩을 완주하세요.
4. 결과 화면에서 **다시 레이스**를 누르면 새 경주를 시작합니다.

WebGL 2를 지원하는 최신 브라우저와 키보드 또는 터치 화면이 필요합니다.

## 조작

| 동작 | 키보드 | 터치 화면 |
| --- | --- | --- |
| 가속 | W 또는 ↑ | GO 길게 누르기 |
| 브레이크 / 정지 후 후진 | S 또는 ↓ | BRAKE 길게 누르기 |
| 왼쪽 / 오른쪽 | A / D 또는 ← / → | ← / → 길게 누르기 |
| 니트로 | 가속 중 Space | 가속 중 ⚡ 길게 누르기 |
| 일시정지 / 계속 | P 또는 Esc | 오른쪽 위 Ⅱ / 계속 버튼 |
| 트랙으로 복귀 | R | 오른쪽 위 ↺ |

## 화면 읽기

- 왼쪽 위: 현재 순위, 랩, 경주 시간
- 왼쪽 아래: 속도와 니트로 잔량. 니트로는 사용하지 않을 때 충전됩니다.
- 오른쪽 아래: 미니맵. 연두색 점은 내 차, 주황색 점은 경쟁 차량입니다.
- 오른쪽 위 ♪: 엔진 사운드 켜기 / 끄기

차는 자동으로 코너를 돌지 않습니다. W로 가속하면서 A/D로 직접 조향하세요. 트랙 바깥에서는 감속하며, 도로에 돌아오면 이탈 전 속도로 복구됩니다. 지름길로 건너뛴 구간은 랩에 반영되지 않지만, 트랙 위 경쟁 차량을 지나치면 순위는 즉시 바뀝니다. 길을 잃으면 R 또는 ↺로 현재 유효한 진행 지점에 복귀할 수 있습니다.

## 문제가 있을 때

- 화면이 비어 있다면 WebGL 2가 지원되는 최신 브라우저에서 새로고침하세요.
- 키보드가 작동하지 않으면 게임 화면을 한 번 클릭한 뒤 조작하세요.
- 휴대전화에서 화면 버튼이 보이지 않으면 가로 화면으로 전환하거나 브라우저를 새로고침하세요.
