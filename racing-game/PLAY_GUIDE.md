# APEX RUSH 게임 시작 가이드

## 1. 준비

- Node.js와 npm이 설치되어 있어야 합니다.
- Chrome, Edge 등 WebGL 2를 지원하는 최신 브라우저를 사용합니다.
- 키보드로 플레이할 때는 W/A/S/D 또는 방향키를 사용합니다. 휴대전화나 태블릿에는 화면 조작 버튼이 나타납니다.

## 2. 처음 실행하기

Windows PowerShell에서 다음 명령을 차례로 입력합니다.

```powershell
cd C:\Study\Codex\codex-vibecoding\racing-game
npm.cmd install
npm.cmd run dev
```

`npm.cmd install`은 처음 한 번만 실행하면 됩니다. 설치를 마치면 터미널에 `Local: http://localhost:5173/`처럼 주소가 표시됩니다. 그 주소를 브라우저에서 엽니다. 주소나 포트가 다르게 표시되면 실제로 출력된 주소를 사용하세요.

> PowerShell에서 `npm` 스크립트 실행이 차단될 수 있어 Windows 명령에는 `npm.cmd`를 사용했습니다. macOS 또는 Linux에서는 `npm install`, `npm run dev`를 사용하면 됩니다.

## 3. 레이스 시작하기

1. 시작 화면에서 **레이스 시작**을 누릅니다. 키보드의 Enter도 사용할 수 있습니다.
2. 화면의 3, 2, 1 카운트다운이 끝나면 경주가 시작됩니다.
3. 가속과 조향으로 AI 차량 5대를 추월하세요. 총 3랩을 완주하면 결과가 표시됩니다.
4. 결과 화면의 **다시 레이스**를 누르면 새 경주가 시작됩니다.

## 4. 조작과 화면

| 동작 | 키보드 | 터치 화면 |
| --- | --- | --- |
| 가속 | W 또는 ↑ | GO 길게 누르기 |
| 브레이크 / 정지 후 후진 | S 또는 ↓ | BRAKE 길게 누르기 |
| 왼쪽 / 오른쪽 | A / D 또는 ← / → | ← / → 길게 누르기 |
| 니트로 | 가속 중 Space | 가속 중 ⚡ 길게 누르기 |
| 일시정지 / 계속 | P 또는 Esc | 오른쪽 위 Ⅱ / 화면의 계속 버튼 |
| 트랙으로 복귀 | R | 오른쪽 위 ↺ 버튼 |

- 왼쪽 위에는 **현재 순위, 랩, 경주 시간**이 표시됩니다.
- 순위는 트랙 위 차량 위치를 기준으로 바뀝니다. 랩 수는 코스를 유효하게 주행했을 때만 올라갑니다.
- 왼쪽 아래에는 **속도와 니트로 잔량**이 표시됩니다. 니트로는 사용하지 않을 때 조금씩 충전됩니다.
- 오른쪽 아래 **미니맵**에서 연두색 점은 내 차, 주황색 점은 경쟁 차량입니다.
- 오른쪽 위 ♪ 버튼을 누르면 엔진 사운드를 켜거나 끌 수 있습니다.
- 차는 자동으로 길을 따라가지 않습니다. W로 가속하면서 A/D로 직접 코너를 돌아야 합니다.
- 트랙 바깥으로 주행하면 속도가 줄고, 도로에 다시 올라오면 이탈 전 속도로 즉시 돌아갑니다. 멀리 떨어진 지점으로 지름길을 가면 랩 진행도는 오르지 않습니다. 길을 잃으면 R 또는 ↺ 버튼으로 현재 진행 지점에 복귀하세요.
- 다른 차량과 충돌해도 감속합니다.

## 5. 종료와 다시 실행

개발 서버를 종료하려면 명령을 실행 중인 터미널에서 `Ctrl+C`를 누릅니다. 다음에 플레이할 때는 프로젝트 폴더에서 `npm.cmd run dev`만 다시 실행하면 됩니다.

## 문제 해결

- 화면이 비어 있다면 WebGL 2가 지원되는 최신 브라우저인지 확인하고 새로고침하세요.
- 주소가 열리지 않으면 개발 서버가 실행 중인지 확인하고, 터미널에 표시된 **실제 Local 주소**를 사용하세요.
- 키보드가 작동하지 않으면 게임 화면을 한 번 클릭한 뒤 조작해 보세요.
- 배포용 파일을 만들려면 `npm.cmd run build`를 실행하세요. 결과물은 `dist` 폴더에 생성됩니다.
