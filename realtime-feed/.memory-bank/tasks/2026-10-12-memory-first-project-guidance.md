## 목표와 근거

사용자가 `AGENTS.md`의 프로젝트 문서 참조와 메모리 우선 절차를 요청했다.

- [프로젝트 지침](../../AGENTS.md)
- [메모리 스킬](../../.agents/skills/guestbook-memory-bank/SKILL.md)

## 할 일과 완료 조건

- `AGENTS.md`에 스킬·기본 노트 6개·작업 카드·프로젝트 문서 링크를 추가한다.
- 스킬의 읽기 순서를 같은 기준으로 맞춘다.
- Markdown·상대 링크·스킬 구조를 검사하고 결과를 기록한다.
- 제품 코드·의존성·외부 서비스는 이번 변경에서 제외한다.

## 실제 결과와 검증

`AGENTS.md`에 문서 링크와 메모리 우선 작업 절차를 추가했다.
스킬도 지침 → 기본 노트 6개 → 관련 카드 → 기준 문서 순서로 맞췄다.
Markdown·상대 링크·스킬 구조 검사가 통과했다. [검증 기록](../verification-log.md)
제품 코드는 변경하지 않았으며 앱 검사를 다시 실행할 변경은 없다.
차단 사유는 없다. 다음 행동은 사용자 UI 확인 후 작은 보완이다.
