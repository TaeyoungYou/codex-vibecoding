# Vercel 공개 운영 배포

최종 갱신일: 2026-10-14
상태: `done`
적용 범위: 검증한 방명록 소스의 Production 환경·공개 운영 주소·실제 검증

## 목표와 근거

사용자가 미리보기 확인 후 괜찮다며 다음 단계 진행을 요청했다.
직전 설명의 공개 운영 배포 단계로 진행한다.
[PRD][prd]와 [구현 계획][plan]의 실제 배포 기준을 따른다.

## 할 일과 완료 조건

- 기존 전용 Vercel 대상과 Production 공개 변수 3개를 확인한다.
- 미리보기와 같은 앱 소스를 Production으로 빌드·배포한다.
- 별도 Vercel 인증 없는 브라우저에서 운영 주소·익명 인증·주요 연동을 검증한다.
- 검증 게시물·파일만 정리하고 기존 데이터·미리보기 보호를 보존한다.
- README와 관련 메모리에 URL·결과·미검증을 기록한다.

예상 변경 파일은 README와 작업 기록이다.
제품 동작·DB 구조·다른 앱·Git commit/push·자동 배포 연결은 제외한다.
기존 통과한 검사는 반복하지 않으며 새 운영 환경의 실제 검증을 수행한다.

## 실제 결과와 다음 행동

메모리와 완료된 미리보기 카드를 재확인했다.
전용 연결 대상과 Node.js 24 설정을 재확인했다.
Production에 공개 변수 3개만 추가하고 `vercel deploy --prod --no-wait`로 배포했다.
실제 target은 Production, 상태는 Ready이며 고정 운영 주소가 배정됐다.
운영 주소는 [README][readme]에 기록했다.

- 별도 Vercel 인증·우회 헤더·사전 쿠키 없는 두 브라우저의 공개 접속: 통과.
- 독립 익명 인증·동일 닉네임의 권한 구분·타인 RPC와 직접 쓰기 거절: 통과.
- 이미지·그림 혼합 저장·획 1→2 재편집·생성/수정 실시간 반영: 통과.
- 열린 초안 유지·재방문·오프라인 삭제 후 복구·기존 게시물 보존: 통과.
- 데스크톱·390px·320×568·Tab 제한: 통과, 가로 넘침 없음.
- 검증 게시물과 실제 미디어 3개 정리: 통과.
- 검사 구간 브라우저 런타임 오류: 0개.
- 실제 운영 JS의 공개 설정 일치·작업자 비밀과 로컬 OIDC 값 미포함: 통과.

README와 관련 메모리를 갱신했다. 제품 코드·DB 구조·Git push는 변경하지 않았다.
미리보기 보호는 유지하며 방문자는 고정 운영 주소를 사용한다.
Git 자동 배포 연결, 기존 전체 출시 인수 공백·실기기 검증과 번들 경고는 남아 있다.
다음은 공개 주소 공유와 필요한 추가 검증·운영 점검이다.
