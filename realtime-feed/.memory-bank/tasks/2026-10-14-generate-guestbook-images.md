# 방명록 이미지 3종 생성

최종 갱신일: 2026-10-14
상태: `done`
적용 범위: 승인된 이미지 생성 문서를 바탕으로 자산 생성·검수·저장

## 목표와 기준

[생성 문서](../../docs/image-generation-prompts.md)의 히어로·메모·포트폴리오 이미지를 만든다.
imagegen 내장 도구를 사용하며 포트폴리오 화면은 실제 앱 캡처를 참조한다.

## 할 일과 제외할 일

- 실제 앱을 샘플 모드로 실행해 개인 정보 없는 화면을 캡처한다.
- 이미지 3종을 각각 생성하고 검수해 output/imagegen/에 저장한다.
- 생성 문서와 진행·검증·다음 행동 노트를 갱신한다.
- 앱 코드·운영 데이터·DB·배포·Git 원격은 변경하지 않는다.

## 완료 조건과 검증

- 3개 최종 이미지와 실제 화면 참조가 프로젝트에 존재한다.
- 배경 여백·메모 손과 펜·포트폴리오 화면 보존을 시각적으로 확인한다.
- 실제 파일 크기·비율·문서 링크·Markdown 형식을 확인한다.

## 실제 결과와 다음 행동

샘플 모드의 실제 화면을 1440×900px로 캡처하고 참조로 사용했다.
내장 image_gen으로 문서의 프롬프트 3개를 그대로 실행해 PNG 3개를 생성했다.
히어로 여백·손과 펜·실제 화면 구성과 주요 한글 문구를 시각적으로 확인했다.
원본을 보존하고 프로젝트에 복사했으며 크기·용량·RGB PNG를 확인했다.
