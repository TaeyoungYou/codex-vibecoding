# 저장소 전체 작업 Git 동기화

최종 갱신일: 2026-10-15
상태: `in progress`
적용 범위: 상위 저장소의 완료 작업 커밋·원격 main 통합·push

## 목표와 기준

사용자의 저장소 전체 push 요청에 따라 이미지·영상·관련 문서를 동기화한다.
원격에 먼저 병합된 랜딩페이지와 기존 작업 기록을 보존한다.
[프로젝트 지침](../../AGENTS.md)의 선택적 스테이징과 공백 검사를 따른다.

## 할 일과 제외할 일

- 완료 자산·영상 소스·문서를 포함하고 의존성·환경 파일·임시 실행 로그는 제외한다.
- Remotion 타입·형식, 자산과 영상 해시, 스테이징된 공백을 확인한다.
- 원격 변경을 통합한 뒤 push하고 실제 원격 main과 로컬 HEAD를 비교한다.
- 제품 기능·DB·배포 설정은 수정하지 않는다.

## 완료 조건과 실제 결과

- 완료 조건: 관련 작업 반영, 원격 변경 보존, push 성공과 원격 해시 일치.
- 실제 결과: 전체 변경 목록과 파일 크기 확인, 원격 fetch 완료.
- 원격 랜딩페이지 기록과 로컬 이미지·영상 기록의 통합·push는 진행 중이다.
- 차단 사유 없음. 완료 후 실제 검증 결과를 갱신한다.
