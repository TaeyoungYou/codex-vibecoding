# 웹앱과 연결되는 히어로·작성 장면 이미지 수정

최종 갱신일: 2026-10-14
상태: `done`
적용 범위: 기존 이미지 1·2의 방향 수정과 새 버전 생성

## 목표와 기준

사용자는 종이 배경과 종이에 메모하는 장면이 웹앱과 관련이 약하다고 지적했다.
실제 방명록의 콘텐츠 카드·작성 모달을 참조해 온라인 사용 경험이 드러나게 한다.
imagegen 스킬과 기존 흑백·라이트 테마를 따른다.

## 할 일과 제외할 일

- 로컬 샘플 모드에서 콘텐츠 카드·작성 모달의 참조 이미지를 캡처한다.
- 히어로·인사 입력 장면을 새 버전으로 생성하고 원본은 보존한다.
- 생성 문서의 현재 프롬프트·선택 파일·검수 결과를 갱신한다.
- 앱 코드·운영 데이터·DB·배포·포트폴리오 이미지는 변경하지 않는다.

## 완료 조건과 검증

- 글·이미지·그림 카드가 나타나는 히어로와 실제 웹앱 입력 장면의 PNG를 저장한다.
- 실제 참조 화면과 구성·주요 문구를 대조하고 파일·문서 링크를 확인한다.

## 실제 결과와 다음 행동

실제 글·이미지·그림 카드와 작성 모달을 로컬 샘플 모드에서 캡처했다.
내장 image_gen으로 웹앱 카드 배경과 노트북의 실제 모달 입력 장면을 생성했다.
주요 내용·문구·중앙 여백·손의 형태를 시각 검사했다.

- [히어로 v2](../../output/imagegen/hero-background-v2.png): 1672×941px.
- [입력 장면 v2](../../output/imagegen/leaving-a-note-v2.png): 1448×1086px.
- [현재 프롬프트와 결과](../../docs/image-generation-prompts.md)를 갱신했다.
- [이전 문서](../../docs/image-generation-prompts-v1.md)와 첫 PNG는 보존했다.

두 파일은 불투명 RGB PNG이며 복사본의 SHA-256이 생성 원본과 일치했다.
운영 데이터 변경이나 게시물 저장 없이 초안만 준비했다.
문서 검사는 검증 기록에 남긴다. 다음은 필요할 때 자산 적용 검토이며 차단 사유는 없다.
