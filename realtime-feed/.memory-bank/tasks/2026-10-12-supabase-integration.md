# Supabase·API·익명 인증 연동

최종 갱신일: 2026-10-14
상태: `done`
적용 범위: 기존 방명록 UI의 실제 저장·익명 인증·미디어·실시간 연결

## 목표와 근거

사용자가 연동 계획 작성과 구현 진행을 명시 요청했다.
[연동 계획][integration-plan]을 따른다.
변경 대상은 src/, supabase/, tests/, 설정·환경 예시·README와 작업 기록이다.
이메일·비밀번호 로그인, 다른 앱, 유료 서비스 임의 선택과 Vercel 배포는 제외한다.

## 완료 조건과 검증

- 닉네임과 실제 익명 계정·프로필, 작성자 UUID 권한을 연결한다.
- 게시물·미디어·획·버전·정리 작업의 트랜잭션과 실패 초안 보존을 검증한다.
- 타입·빌드·단위·SQL 검사 후 전용 프로젝트에서 실제 API·브라우저 검증을 수행한다.
- 미준비 원격 환경과 미검증 동작은 완료와 구분한다.

## 현재 결과와 선행 조건

익명 인증·API·미디어·실시간·정리 작업 코드와 고정 버전 의존성을 추가했다.
타입·빌드, 단위 22개, 테스트 응답 기반 Chromium 2개가 통과했다.
전용 realtime-feed에 DB 마이그레이션 3개와 Edge Function 2개를 적용했다.
Supabase CLI 2.120.0은 설치했으며 Docker 전체 스택은 실행하지 않았다.
익명 인증 한 항목만 활성화했다. 공개 연결 설정과 비밀은 Git 제외 파일에 둔다.
실제 API 검사 2개와 독립 Chromium 세션 검사 1개를 통과했다.
그림 획 재편집·실시간 생성/수정·재연결 후 삭제·실패 초안 보존을 확인했다.
미디어 위조·타인 경로·덮어쓰기·직접 삭제·정리 큐 접근 거절을 확인했다.
정리 함수의 배포 파일 누락을 수정하고 실제 삭제·24시간 만료·Cron 성공을 확인했다.
읽던 페이지 밖의 오래된 글이 새 글로 집계되는 문제도 회귀 검사와 함께 수정했다.
로컬 SQL 내용은 그대로 두고 파일명만 원격 적용 버전에 맞췄다.
세부 결과와 남은 실기기·배포·용량 경고는 [검증 기록](../verification-log.md)에 있다.
