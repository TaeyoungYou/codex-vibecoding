B안은 중앙 단일 열·흑백 라이트·작성/수정 모달을 사용한다.
실제 Supabase 연결은 명시 요청 전까지 제외한다. 로그인·회원가입도 현재 범위 밖이다.
UI 변경은 새로고침 시 사라진다. 실제 권한·저장·실시간 연결과 구분한다.
빠른 Escape 문제를 수정했으며 초점 제한은 Radix에 맡긴다.
메모리 우선 읽기와 프로젝트 문서 링크는 [프로젝트 지침](../AGENTS.md)에 정리한다.
실제 연동 제외 결정은 이번 연동 요청 범위에서 대체한다.
인증은 기존 PRD의 익명 방식이며 계정 로그인·Vercel 배포 승인은 포함하지 않는다.

FIFO 선택은 기존 PRD의 다음 시도 시각 우선 정렬을 대체한다.
사용자는 FIFO 설명 뒤 문서 반영을 요청했으며 [작업 카드](tasks/2026-10-14-cleanup-fifo-docs.md)에 기록한다.
제품 코드·DB 구조 변경은 이 문서 작업에 포함하지 않는다.

Vercel 배포 제외 결정은 이번 별도 요청의 미리보기 범위에서 대체한다.
CLI가 첫 배포를 Production으로 초기화한 결과는 확인 후 제거했다.
최종 Preview 검증과 공개 운영·Git push 승인 여부를 구분한다.
이후 공개 운영 배포 진행 요청으로 미리보기 한정 범위를 확대했다.
Production에 같은 공개 연결을 설정하고 고정 운영 주소를 공개했다.
미리보기 보호는 유지하며 Git push·자동 배포 연결은 추가하지 않았다.
