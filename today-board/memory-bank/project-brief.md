# 프로젝트 개요

## 앱 이름

오늘의 집중 보드

## 한 줄 목표

사용자가 하루에 하나의 집중 목표를 작성하고, 그날의 간단한 할 일 목록을 관리할 수 있도록 한다.

## 첫 번째 버전 범위

- 오늘 날짜를 표시한다.
- 사용자가 하나의 집중 목표를 작성할 수 있도록 한다.
- 사용자가 할 일을 추가할 수 있도록 한다.
- 할 일을 완료 상태로 표시할 수 있도록 한다.
- 할 일을 삭제할 수 있도록 한다.
- 데이터를 `localStorage`에 저장한다.
- 할 일이 없을 때 친근한 빈 상태 화면을 표시한다.

## 범위에서 제외

- 인증
- 백엔드 데이터베이스
- 팀 공유 기능
- 캘린더 연동
- 알림
- 배포
- 외부 UI 라이브러리

## 성공 기준

- 앱이 브라우저에서 정상적으로 실행된다.
- 새로고침 후에도 집중 목표와 할 일이 유지된다.
- 모바일과 데스크톱 환경 모두에서 인터페이스를 읽기 쉽다.
- 구현은 `AGENTS.md`의 지침을 따른다.
