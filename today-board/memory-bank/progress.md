## 검증 상태

- `node --check today-board/script.js`를 통과했다.
- 일반 Chrome, `http://127.0.0.1:4173/`에서 다음을 확인했다.
  - 기기 기준 한국어 날짜 및 최초 빈 상태
  - 목표 자동 저장, 버튼/Enter 추가, 완료/Space 완료 취소, 삭제
  - 새로고침 및 새 탭 재접속 후 목표·목록·순서·완료 상태 복원
  - 빈 문자열/공백 입력 차단, 입력 후 안내 해제
  - 긴 한국어 문장과 HTML 형태의 특수문자가 텍스트로 표시됨
  - 데스크톱 1280px 및 모바일 375px에서 가로 넘침 없음
  - 모바일 긴 문장과 삭제 버튼의 경계가 겹치지 않음
  - Tab 순서, 입력/버튼/체크박스의 3px 포커스 표시
  - 키보드 삭제 후 다음 항목으로 이동, 마지막 항목 삭제 후 입력창으로 이동
  - 마지막 항목 삭제 후 빈 상태 복귀, 목표와 목록을 비운 상태의 저장
  - 콘솔 오류/경고 없음
- 별도 임시 테스트 서버에서 실제 앱 스크립트에 함수 내부 모의 저장소를 주입해 Chrome에서 다음을 확인했다. 실제 브라우저 저장소와 설정은 변경하지 않았다.
  - 손상 JSON 및 잘못된 데이터 구조에서 빈 보드와 오류 안내 표시
  - 읽기 실패 후에도 할 일 추가 가능
  - 쓰기 실패 중에도 목표·할 일·완료 상태를 현재 화면에서 유지하고 안내 표시
  - 일시적 쓰기 실패 이후 다음 변경에서 저장에 성공하면 안내 해제
- 테스트용 입력은 정리했다. 테스트 서버와 캡처는 저장소 밖의 임시 디렉토리에 두었으며 의존성을 설치하지 않았다.

## 브라우저에서 다시 확인하는 방법

1. `today-board/`를 정적 HTTP 서버로 제공하고 같은 호스트와 포트를 사용한다. 이번 검증 주소는 `http://127.0.0.1:4173/`이다.
2. 목표와 할 일 두 개를 입력하고 하나를 완료한 뒤 새로고침하여 복원을 확인한다.
3. 완료를 취소하고 항목을 모두 삭제해 빈 상태 복귀를 확인한다.
4. 빈 입력, 긴 한국어 문장, Tab/Enter/Space 조작을 확인한다.
5. 화면 너비를 1280px와 375px로 바꾸어 줄바꿈과 버튼 위치를 확인한다.

## 남은 검증 및 제한

- Safari/Firefox, 스크린 리더, 실제 모바일 기기, 실제 한글 IME 조합은 검증하지 않았다.
- 저장 오류는 모의 저장소로 재현했다. 실제 저장 용량 소진이나 브라우저 설정 차단은 수행하지 않았다.
- 실제 자정을 넘기는 장시간 검증은 수행하지 않았다. 구현은 날짜만 갱신하고 저장 내용을 초기화하지 않는다.
- 브라우저/접속 주소가 달라지거나 사이트 데이터를 삭제하면 기존 내용이 보이지 않을 수 있다.
- 배포, 외부 서비스 연동 및 추가 기능은 이번 범위에 포함하지 않는다.
