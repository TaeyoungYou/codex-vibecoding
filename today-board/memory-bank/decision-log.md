# 의사결정 기록

## v1 구현 결정

- **구성:** 빌드 도구와 외부 라이브러리 없이 `index.html`, `styles.css`, `script.js` 세 파일로 구성한다. 초보자가 구조를 이해하고 실행하기 쉽게 하기 위해서다.
- **저장:** `localStorage`의 단일 키 `today-board-state-v1`에 `{ focus: string, tasks: [{ id, text, completed }] }`를 저장한다. 배열 순서를 화면 순서로 사용하고 새 할 일은 끝에 추가한다.
- **저장 오류:** 손상된 데이터나 저장소 접근 실패로 앱을 중단하지 않는다. 불러오기 실패 시 빈 보드와 안내를 표시하되, 사용자가 변경하기 전에는 기존 저장 값을 덮어쓰지 않는다. 쓰기 실패 시 현재 화면의 입력을 유지하고 새로고침 시 사라질 수 있음을 알린다.
- **날짜:** 기기의 로컬 날짜를 한국어로 표시하고 주기적으로 갱신한다. 날짜가 바뀌어도 목표와 할 일은 자동으로 지우지 않는다.
- **입력과 접근성:** 공백만 있는 할 일은 등록하지 않는다. 사용자 입력은 HTML이 아닌 텍스트로 표시한다. 기본 체크박스와 입력 라벨·포커스 표시를 사용하고, 삭제 후 포커스를 남은 항목 또는 입력창으로 옮긴다.
- **범위:** 로그인, 백엔드, 공유, 알림, 배포와 날짜별 기록은 v1에 포함하지 않는다.

## 이후 결정할 사항

할 일 필터, 완료 항목 일괄 삭제, 텍스트 내보내기의 필요성과 우선순위는 실사용 피드백을 보고 정한다.
