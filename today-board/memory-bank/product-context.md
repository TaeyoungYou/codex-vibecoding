# 제품 컨텍스트

## 대상 사용자

하루를 시작할 때 하나의 중요한 집중 목표와 몇 가지 간단한 할 일을 정하고 싶은 초보 사용자.

## 사용자 요구

사용자에게는 복잡한 생산성 관리 시스템이 필요하지 않다. 대신 다음 질문에 간단히 답할 수 있는 차분하고 단순한 보드가 필요하다.

- 오늘 무엇에 집중해야 하는가?
- 오늘 끝내야 할 몇 가지 할 일은 무엇인가?
- 이미 완료한 것은 무엇인가?

## UX 톤

- 차분한 분위기
- 미니멀한 구성
- 한국어 문구는 자연스럽고 부담 없이 격려하는 느낌으로 작성
- 복잡한 대시보드나 과도한 생산성 압박은 피함

## UI 참고사항

- 첫 화면은 랜딩 페이지가 아니라 실제 앱 화면이어야 한다.
- 입력 요소와 주요 액션은 사용자가 바로 이해할 수 있어야 한다.
- 빈 상태 문구는 사용자가 자연스럽게 시작할 수 있도록 도와야 한다.
- 모바일 레이아웃에서는 요소가 서로 겹치지 않아야 한다.
