# 캘린더 구현 검증 결과

- 검증일: 2026-10-07
- 환경: Node.js v24.12.0, 실제 Chrome 브라우저
- 미리보기: `http://127.0.0.1:4175/`
- 일정 동작 검증: 같은 코드를 별도 포트 4176에서 실행해 미리보기의 저장 데이터와 분리

## 자동 검증

`node --check app.js`, `node --check preview.cjs`가 통과했다.

`node --test tests/app.test.mjs`의 6개 테스트가 통과했다.

1. 월요일 시작 날짜 배열과 4·5·6주 계산
2. 윤년·평년, 연도 경계, 100년 이전 로컬 날짜와 잘못된 날짜 키
3. 날짜별 일정 저장·복원, 중복 제목의 독립 삭제와 빈 날짜 정리
4. 추가·삭제 쓰기 실패 시 기존 메모리 목록과 저장값 유지
5. 손상된 JSON과 잘못된 날짜·제목·ID·버전 거부 및 원본 보존
6. 공백 제목 거부와 마크업 모양의 제목을 문자열로 보존

저장소 접근 오류와 손상 데이터에 대한 검증은 자동 테스트에서 수행했다. 브라우저 저장소를 인위적으로 변경해 오류를 주입하지 않았다.

## 브라우저 동작 검증

- 초기 현재 월 표시 및 일정 카드 숨김 확인
- Enter로 날짜 선택 후 일정 카드 표시 확인
- 공백 입력 안내 및 입력란 초점 유지 확인
- Enter와 추가 버튼으로 일정 생성 확인
- 다른 날짜의 목록 분리 확인
- 새로고침 후 미선택 상태 시작 및 저장된 일정 복원 확인
- 같은 제목 두 개 중 하나만 삭제되는 동작 확인
- 삭제 후 다음 삭제 버튼 또는 제목 입력란으로 초점 이동 확인
- 마지막 일정 삭제 후 빈 상태 안내 확인
- 날짜·월 변경 시 선택과 일정 카드 상태의 일치 확인
- 마크업 모양의 제목이 HTML 요소로 해석되지 않는 동작 확인
- 삭제 성공 후 이전 입력 오류의 `aria-invalid` 상태가 해제되는 동작 확인

검증용으로 생성한 일정은 검증 후 해당 항목만 삭제했다. 별도 검증 탭과 포트 4176의 서버를 정리하고 포트 4175의 미리보기는 유지한다.
